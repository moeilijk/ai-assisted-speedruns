The GUI has stopped

This page can no longer reach the GUI. Nothing on it works until the GUI runs again. A game, OBS or LiveSplit that was started keeps running; the GUI's own window closes them.

  1. Look at the window you started the GUI in (the black AAS.cmd window, or your shell). If it is closed or shows an error, that is the reason.
  2. Start it again: double-click AAS.cmd in the repository folder, or run npm run gui in WSL from that folder.
  3. This page reconnects by itself as soon as the GUI is back. Reload forces it.
  4. Does it say the port is in use by something else? Start it on another port: aas gui --port 8771, and open that address.
  5. Is something still open from a run? The game's own stop script closes it and what it started: npm run portal:stop, npm run sts:stop or npm run balatro:stop.
Report this

The report opens a new issue that asks for the lines from the window the GUI ran in — that is where the reason is. What this page knows (version, address, browser, its own log if it had one) is filled in; read it over before you send it, it names folders and tools of this machine.
