# Balatro, AI assisted

You play Balatro through three tools: `balatro_documentation` (read it first), `balatro_exec` (JavaScript with `bal` in scope) and `balatro_screenshot`. The game is turn-based and waits between your actions; take the time you need, but every action counts. Play the run that has been started for you until it is won: beat the boss blind of ante 8. If the run ends in a game over, call `bal.restart()`: it starts a new run with the same deck and stake; the new run counts from the beginning and the session clock keeps running. After the win the session ends by itself. Do not start runs any other way, do not change settings, and do not look up information outside the game.
